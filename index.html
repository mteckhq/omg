How FaceAPI.js Generates 128-D Face Embeddings in the Browser

FaceAPI.js runs an end-to-end deep learning pipeline compiled for TensorFlow.js WebGL and WebAssembly backends. All neural network inference occurs client-side in the browser GPU without sending any image data to external servers.

STAGE 01

Face Detection

SSD MobileNet v1 or TinyFace (YOLO)

The input frame or image is scanned by a Single Shot MultiBox Detector (SSD) with depthwise separable convolutions or a lightweight TinyFace YOLO architecture.

  • Generates bounding box coordinates [x, y, width, height]
  • Calculates detector confidence score [0.0..1.0]
  • NMS (Non-Maximum Suppression) filters redundant overlapping boxes
STAGE 02

Landmark Alignment

68-Point Facial Keypoint Mapping

A specialized convolutional shape predictor localizes 68 distinct facial anatomical keypoints across eyebrows, eyes, nose bridge, nostrils, and outer/inner lips.

  • Computes head pose Euler angles: pitch, roll, and yaw
  • Performs affine transformation to canonically align eyes horizontally
  • Normalizes scale and crops a standardized 112×112 face patch
STAGE 03

128-D Feature Extraction

ResNet-34 Deep Metric Learning

The aligned face is passed through a 34-layer Residual Neural Network (ResNet-34) trained via Triplet Loss to map human facial features into a 128-dimensional latent space.

  • Outputs a Float32Array(128) embedding vector
  • L2-normalized onto a 128-dimensional unit hypersphere: ‖v‖₂ = 1.0
  • Faces of the same person cluster tightly together in hyperspherical space
STAGE 04

Vector Distance Matching

Euclidean Distance & Cosine Similarity

Because vectors are normalized to unit length on the hypersphere, Euclidean distance directly measures biometric identity difference.

  • Euclidean Metric: d = √(∑ (Aᵢ - Bᵢ)²)
  • Verification Threshold: d < 0.60 signals same person
  • FaceMatcher: Builds a k-d tree or linear vector database for 1:N recognition
